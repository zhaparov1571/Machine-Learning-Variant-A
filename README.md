## Состав проекта
- `PR1_Environment.ipynb` — загрузка и первичный осмотр данных
- `PR2_EDA.ipynb` — разведочный анализ, гистограмма, boxplot и категории
- `PR3_Preprocessing.ipynb` — train/test, заполнение пропусков, кодирование и масштабирование
- `PR4_Regression.ipynb` — линейная регрессия и метрики
- `PR5_Classification.ipynb` — логистическая регрессия и матрица ошибок
- `PR6_Text_Classification.ipynb` — наивный Байес, CountVectorizer и TF-IDF
- `PR7_Random_Forest.ipynb` — сравнение дерева и случайного леса
- `data/tips_sample.csv` — небольшой учебный табличный датасет

## Запуск
1. Установить Python 3.11 или новее.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Запустить Jupyter: `jupyter lab`.
4. Открывать notebook-файлы по одному и выполнить `Restart Kernel and Run All`.

Ноутбуки рассчитаны на запуск из корня репозитория или из папки `notebooks/`.

## Примечание
Датасет `tips_sample.csv` создан для учебной демонстрации и содержит несколько специально добавленных пропусков и потенциальный выброс для практики EDA и предобработки.
